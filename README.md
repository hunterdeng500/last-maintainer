# 最后一位维护员 × bug大乱斗

一款中文俯视角像素探索游戏。人类离开之后，小镇仍靠旧系统运转。你背着工具包走过街道，在现场发现六种异常，阅读日志与配置，再决定修复系统，还是利用漏洞。

沿用原作六个技术故障和三种结局，改为可行走的小镇：道路、建筑、树木、水域、区域门禁、昼夜变化与维护日志。约 10–15 分钟一局，具体取决于阅读与探索速度。视觉和探索节奏参考《星露谷物语》，像素图形全部由程序原创绘制；本作聚焦 bug 调查与维护抉择，没有务农、恋爱或经营系统。

小镇现采用 **2.5D 斜俯视**表现：六处建筑分别绘制亮屋顶、南立面与暗侧墙，道路下沉、河岸露出石壁，台阶与桥面体现高度。人物、树木、建筑和道具按脚底位置遮挡，软投影随昼夜变化；维护员带工具包与四向步态，行走有短加速与制动，镜头平滑跟随并略微看向移动方向。全部仍由原生 Canvas 2D 绘制和缓存，零运行依赖；手机横屏会保持角色可辨，系统“减少动态效果”设置可关闭环境微动与冲刺尘土。详见 [CHANGELOG-25d.md](CHANGELOG-25d.md)。

## 本地运行

无需构建、后端、CDN 或素材包。安装 Python 3 后，在项目根目录运行：

```bash
python3 -m http.server 8765
```

浏览器打开 <http://127.0.0.1:8765/>。JavaScript 使用原生 ES modules，请通过 HTTP 打开，避免 `file://` 的模块加载限制。

## 操作

| 操作 | 键盘 / 鼠标 |
| --- | --- |
| 行走 | `WASD` / 方向键；点击地面自动寻路 |
| 奔跑 | 行走时按住 `Shift` |
| 调查 / 交互 | 靠近目标后按 `E` / `Space`，或点交互按钮 |
| 前往终端 | 点击场景中的终端，走近后调查 |
| 地图 | `M` |
| 维护日志 | `J` |
| 调查面板：日志 / 配置 | `L` / `C` |
| 调查面板：修复 / 利用 | `F` / `X`，需要先查看两类证据 |
| 关闭面板 | `Esc` |

先找到异常，再查看该终端的**日志**和**配置**，两个证据都读过后才能选择**修复**或**利用**。选择会保存，并改变镇上的场景和最终结局。地图用于查看位置与进度，正常游玩需要亲自走到现场。

游戏时间每现实秒推进约 4 分钟，阅读面板时暂停。午夜折扣门与时间有关；可以走近西街长椅休息至 `00:10`，也可以在夜市调查面板选择“等到次日 00:10”，无需等待完整的昼夜循环。

## 区域与故障

| 区域 | 现场 | 技术原因 |
| --- | --- | --- |
| 西街 | 负金币铺 | `int16` 整数溢出 |
| 西街 | 午夜折扣门 | 跨午夜时只比较 `HH:MM` |
| 中区 | 半开的门 | 竞态 / 缺少互斥 |
| 中区 | 还活着的 Boss | 缓存未失效 |
| 东岸 | 一跳出界 | 米 / 厘米单位混用 |
| 东岸 | 连体分身 | 浅拷贝共享引用 |

完成西街两处维护后开放中区；完成前四处后开放东岸。六处处理完毕后，按选择得到全修复、全利用或混合结局：全修复让系统继续运转，也让维护继续；全利用让旧系统崩塌，通向自由。

## 存档

进度保存在当前浏览器、当前站点的 `localStorage` 中。刷新后可从标题页继续；新游戏会开始新的维护记录。不同浏览器、端口或域名之间不共享存档。清除网站数据也会删除存档。

## 上传到 itch.io

在项目根目录打包以下运行文件，确保 `index.html` 位于 ZIP 根目录：

```bash
zip -r last-maintainer.zip index.html css js
```

在 itch.io 新建项目，类型选 **HTML**，上传 ZIP，并勾选 **This file will be played in the browser**。建议开启全屏按钮。运行包只需 `index.html`、`css/` 与 `js/`，不需要测试、日志、文档或 `legacy/`。

## 代码结构

```text
index.html             页面与面板
css/style.css          像素风界面与响应式布局
js/game.js             游戏循环、交互与面板
js/levels.js           六个故障的叙事、日志、配置和结果
js/world.js            小镇地图、绘制与碰撞
js/scenery.js          六种立体建筑、离屏绘制与落地轮廓
js/player.js           玩家移动与 A* 寻路
js/state.js            进度、时间、存档与结局
tests/browser-smoke.mjs 浏览器冒烟测试
tests/browser-depth.mjs 2.5D 分层、相机与布局验证
CHANGELOG-25d.md        2.5D 视觉与手感改动
CHANGELOG-stardew.md    本次探索版改动
```

原逐关文字 MVP 已归档在 `legacy/`，从本地服务器打开 `/legacy/index.html` 可查看旧版。当前入口保留原来的六种 bug 内容，并校正技术解释与结局含义：全修复对应永远继续维护，全利用对应旧系统崩塌与自由，混合选择保留代价与余地。归档不会参与新版加载。

## 调试与验证

普通地址不开放调试快捷键。开发时打开 <http://127.0.0.1:8765/?debug=1>，可用 `1`–`6` 传送至终端、`T` 快进至下一个午夜，并通过 `window.__maintainer` 检查状态。调试会影响当前存档，建议使用独立浏览器环境。

浏览器冒烟测试使用 Node.js 与 Playwright；它们只用于开发，不进入运行包。测试运行方式和覆盖范围见 [tests/README.md](tests/README.md)。
