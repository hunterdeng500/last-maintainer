# 最后一位维护员 × bug大乱斗

网页可玩 MVP。人类离开后，城市靠旧系统运转；你是最后一个维护员。Bug 以真实技术原因出现。

**核心循环（每关）：** 发现异常 → 查日志 / 看配置 → 定位原因 → 选择 **修复** 或 **利用**。

## 怎么跑

无需构建。任选其一：

```bash
cd last-maintainer
python3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/
```

或：

```bash
npx --yes serve -p 8765
```

也可直接用浏览器打开 `index.html`（部分浏览器对 ES module 的 `file://` 有限制，优先用本地 HTTP）。

## 操作

| 键 | 作用 |
|----|------|
| Enter | 开始 / 结局后回标题 |
| 1–6 | 跳到已解锁关卡 |
| L | 查日志 |
| C | 看配置 |
| F | 修复（需先查过日志+配置） |
| E | 利用（需先查过日志+配置） |
| N | 下一关 / 结局 |

鼠标点按钮同样可用。

## 六关

1. **负金币铺** — int16 溢出  
2. **午夜折扣门** — 只比较 HH:MM  
3. **半开的门** — 竞态 / 无锁  
4. **还活着的 Boss** — 缓存未失效  
5. **一跳出界** — 米/厘米单位混用  
6. **连体分身** — 浅拷贝  

结局按修复/利用比例：**全修 / 全利用 / 混合**。
